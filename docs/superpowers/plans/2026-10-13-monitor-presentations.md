# 桌面监控形态与自定义

用户已确认：默认清晰双行；可切换桌面浮条与任务栏多列宽条；支持实时折线；读取蓝色、生成绿色。普通系统托盘图标保留为独立选项。

## 本次实现

- Core 归一化旧偏好，提供紧凑、双行、面板预设、12–24 px 字号、1–8 项指标及排序。设置页面预览使用明确标注的示例数据。
- 桌面浮条复用只读 `monitor_snapshot`，默认 588×152 逻辑像素。窗口尺寸由原生命令验证，按 DPI、工作区和原右下边距夹紧；整窗可拖动、右键与 Shift+F10 提供动作。
- 折线保留至多 60 个样本和 180 秒；生成与读取独立刻度。空闲时的历史速度标“最近”，不能作为新折线采样；未知、失败、暂停和停止显示缺测，服务身份变化清除旧曲线。
- Windows 任务栏使用同一可执行文件的独立 Win32/GDI 宿主。主进程唯一只读采样，通过有界 NDJSON 管道传输数据和白名单菜单事件。首帧成功后才隐藏桌面态；切回时先恢复桌面态。
- 任务栏适配只使用经 UI Automation 确认的空白区域，不注入 Explorer、不调整其按钮区、不嵌入 WebView。空间或身份不确定时回退桌面态。退出清理我方宿主。

## 兼容与验收边界

Windows 11 不提供官方任务栏扩展区域，首版标为实验适配。参见 [Microsoft Windows 11 specifications](https://www.microsoft.com/en-us/windows/windows-11-specifications) 与 [SetParent DPI 约束](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)。主屏水平任务栏为首期目标；不可确认的环境继续使用桌面态。

分开记录 Core/前端/原生纯函数测试、Vite 隔离浏览器验收和真实任务栏验收。浏览器中的模式命令为夹具，不证明 Explorer 挂载、自动隐藏、多屏或重启恢复已通过。依照此前要求，本轮不操作已安装应用、真实 Explorer 或模型生命周期。

## 2026-10-14 交互收敛

- 字号 8–36px，默认 16px，紧凑预设 14px。指标间距 2px；默认双行 338×120，紧凑预设 225×40。关闭全部标签后紧凑高度 28px，不保留生成标签或标签空行。
- 所有预设默认显示标签，已有显式关闭值保留。`showStatus` 与 `snapToEdge` 新字段默认 false；状态行默认不占高度，状态仍在无障碍语义及悬浮说明中可读。显示时间可独立打开。
- “显示监控”开关以原生实际 `visible` 状态为准。关闭仅结束任务栏宿主并销毁监控浮窗；保留所选形态，关闭时改形态只保存偏好。普通托盘仍是独立选项。
- 拖动保存每次移动的初始窗口与鼠标位置，使用累计位移计算候选矩形，避免吸附后的微小增量被反复归零。吸附关闭时仍限制在工作区内；取消、结束、DPI 改变及销毁清理或重建拖动锚点。
- 预览指标支持指针与键盘排序，松手保存一次，取消不写偏好。开关、字号与布局仍只影响监控展示，不操作模型生命周期。
