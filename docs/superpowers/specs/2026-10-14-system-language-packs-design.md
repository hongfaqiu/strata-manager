# 系统语言与语言包

用户要求：安装时可选择语言，默认根据电脑语言；补充常用语言包。

Windows NSIS 安装器配置十种语言，English 作为不支持语言的回退，显示语言选择器。被动安装、自动更新不显示交互语言框。AppImage/DEB 无统一安装器，因此应用首次启动提供语言选择。系统语言用 Windows 用户 UI 语言、Linux LC_ALL/LC_MESSAGES/LANG；Web 预览使用 navigator.languages。

支持 en、zh-CN、zh-TW、ja、ko、de、fr、es、pt、ru。语言偏好包含 system；新设置自动选择匹配语言，不支持则英文。已有 language 字段视为明确手动选择，不覆盖。Windows 安装器所选语言可作为新用户的明确偏好；本地已保存偏好优先。

现有 i18next 界面字典扩展完整的语言资源。尚未接入 i18next 的高级页面文案保留英文回退，不假称翻译完所有专业页面。应用菜单、公共动作、聊天、模型安装引导及监控公共字典均翻译。语言包检查键与占位符；纯函数测试系统匹配与存量迁移；浏览器验证切换/持久化；NSIS验证交互与自动升级路径。保留停止的服务，不启动推理或操作用户数据。
