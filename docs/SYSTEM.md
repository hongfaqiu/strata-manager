# 系统说明：Strata Manager 0.1.5

本文说明 0.1.5 的组件关系、数据保存和操作边界。验收层级见[验收记录](VERIFICATION.md)，发行结果以同源码的 CI 与[实际发布](https://github.com/hongfaqiu/strata-manager/releases/tag/v0.1.5)为准。配图使用隔离的界面演示数据，报告图中的数值不代表硬件实测结果；完整图文见[更新日志](../CHANGELOG.md)。

## 三个组成部分

| 部分 | 职责 | 运行关系 |
| --- | --- | --- |
| Desktop | React/Tauri 工作区、聊天、监控、连接配置、Benchmark 和更新确认 | 通过本机 IPC 调用独立后台，通过原生 HTTP 桥访问已核验的 Strata 服务 |
| Supervisor | 本机模型登记、进程归属、任务、持久化、观察器、调优和后台管理 MCP | 与桌面分属进程；关闭或重启界面可以保留后台服务 |
| Strata | 实际加载模型、执行推理，提供模型 API 和引擎运行能力 | 使用各模型的配置、运行目录和端口；实际能力取决于已安装运行时与模型 |

关闭界面不等于停止服务。“停止服务”释放对应受管进程；“卸载模型”释放模型资源并保留 API。登录启动、提前准备模型及自动恢复由公共后台设置分别控制。用户明确停止的服务保持“未启动”，不会因界面重新打开或状态轮询自动恢复。

## 本机模型、端口和外部助手

桌面列表以 Supervisor 的本机登记为准。发现只读取候选；导入重新核验并建立应用专用配置快照，保留源配置和权重。移除登记与删除模型文件是不同操作，删除需按实际文件计划另行确认。

桌面桥接受回环 HTTP 地址。端口存在不证明进程属于本应用：运行状态还核验 PID、创建时间、配置、监听端口与受管归属。外部实例可只读显示，明确接管时才重新核验并移交。未知进程、归属不明或忙碌状态会阻止相应变更。Windows 受管树使用 Job Object；Linux 使用进程监护，不能据此声称所有主动脱离进程组的第三方工具后代均已覆盖。

公共设置中的“API 与外部助手”提供连接目标、应用访问 API 的密钥、API 接入示例与 MCP。选择连接目标不会启动或切换当前模型。后台管理 MCP 与官方独立 MCP 是两种归属模式；后台模式可在界面关闭后继续管理。生成的 Codex 后台 MCP 配置使用 600 秒工具超时；官方独立模式的 Codex 配置为 180 秒，其他客户端配置不自动添加该字段。

## 公共聊天默认值

公共默认值共享推理强度、温度、Top-p、Top-k、输出上限、随机种子、系统提示词与 MCP 开关，不共享模型名或依赖模型能力的高级选项。新模型默认继承；已保存专用参数的旧模型保持独立，直到用户主动开启继承。

修改公共值会在继承模型的下一次聊天请求生效，正在生成的请求保持开始时的参数。在参数抽屉修改共享字段并应用后，该模型改用专用值。关闭继承恢复既有专用值；没有专用值时保存当前有效参数。结构化输出的 MCP 限制继续生效。

公共值、各模型的专用值及继承开关分别持久保存。参数抽屉按模型隔离，晚到的旧保存回调不能写入新模型；当前切换模型会重建抽屉并丢弃旧模型未保存的抽屉草稿，不应描述为“切换时保留草稿”。连接密钥和启动配置的页面导航另有保存、放弃或取消的草稿保护。

继承期间只保存高级设置时，会保留模型原有的专用共享参数。之后关闭继承仍能恢复这些值，高级设置编辑不会用公共默认值覆盖它们。
## 凭据、SQLite 和备份

API Key 按服务 ID 保存于系统凭据库，前端只能确认有无密钥，不能读回秘密。连接页保存的是应用访问服务的凭据，不修改服务端鉴权。浏览器开发预览的密钥仅保存在会话内存，不能代替原生凭据验收。

用户应用数据目录中的 `strata-manager.sqlite3` 保存设置、会话、模型登记、任务及统计等状态；会话附件拆入独立表并由事务维护引用。观察器使用 `analytics/journal.sqlite3` 记录使用统计事件，日常统计不要求开启请求正文捕获。高级诊断中的正文捕获另有显式开关与时间范围。

SQLite 会话与附件不等于加密保险库。配置写入有版本冲突检查、原子替换和原文件备份。应用安装更新前以 `VACUUM INTO` 在 `backups/` 创建一致数据库备份；系统凭据、模型权重和运行目录不包含在这份数据库备份中。

## Benchmark 与调优

侧栏提供独立的 Benchmark 入口，内含“上下文档位”和“场景测试”。上下文测试按档位从小到大串行发送请求：预置档位从 8K 到 1M，并补充当前模型的实际上下文上限。默认选中核验上限内且能容纳输出与模板余量的档位，超出上限的预置项不可选。服务运行时以已加载模型的 `/health` 为准；停止时只读本机配置供计划参考，不会为读取上限而启动服务。

使用时，先确认模型已就绪且没有其他推理或管理任务，再选择档位、每档轮数、输出上限和超时，开始有限轮次的测试。每档总预算包含输出预留和模板余量，目标档位不等于实际输入 token 数；分词计数不可用时，准备阶段的输入量标为估算。实际输入、输出和缓存用量取自服务 `usage`，预填充与解码速度取自 `timings`，同时记录首 token 延迟和完整请求耗时。显存与 RAM 为每秒采样的整卡／整机读数，缺失值保持未知。

结果包含预填充速度、解码速度和请求耗时三张折线图，按成功请求计算各档均值，表格保留逐次测量。可复制结果图片、导出 PNG，以及导出含测试条件的 JSON/CSV；复制图片依赖当前环境的图片剪贴板能力，失败时可改用 PNG。预热、缓存与其他程序仍会影响结果，图表本身不能证明冷启动或无缓存性能。

“场景测试”保留七类场景并固定单请求串行执行；旧版并发压力测试报告仍可查看和导出，不作为新建压力测试入口。两种测试在运行期间不能切换；停止测试或切换模型会取消后续工作。

桌面把聊天和 Benchmark 视为推理忙碌，协调调优、服务切换、运行任务与更新操作。Benchmark 切换模型或取消时终止后续工作；调优由独立后台执行，具备配置应用与恢复核验。桌面互斥不保证其他 API 客户端不会同时发送请求；可复现测量仍需记录模型、服务身份、缓存、并发、资源余量和外部负载。

## 应用更新与引擎下载

应用更新来自项目稳定通道的 `latest.json`。自动检查和安装确认分开；确认绑定当前展示的版本，下载返回成功需经过 Tauri updater 内置公钥的签名校验。安装前再次核验任务、调优、服务空闲与数据库备份。独立后台包切换核验包身份和原进程退出，候选启动失败时尝试恢复原版本；这不是任意安装器失败或数据库迁移的通用自动回滚保证。Tauri 签名不等于 Windows Authenticode 发布者证书。

引擎 ZIP 可使用官方来源、本地文件或已保存的 HTTPS 镜像/模板。来源替换只改变传输位置，官方版本、文件名、长度与 SHA256 仍决定接受条件。网络来源测试最多读取 64 KiB，只验证可访问性、长度信息和 Range 行为；本地文件测试读取完整文件并校验 SHA256。实际安装对完整 ZIP 再做长度与官方 SHA256 核验，同时核验对应源码、解包路径及替换范围。

更新事务日志保存替换清单、原程序备份和原/新文件哈希，保护模型、配置、会话和未知文件。失败按记录恢复文件与登记；回滚失败必须显示未完成并保留诊断资料。原服务是否恢复与原先的运行/停止状态相关，不能把“更新成功”理解为自动启动全部模型。

## 状态趋势与验收边界

独立桌面监控浮条默认关闭，采用紧凑的纯指标布局；按住任意位置拖动，通过原生右键菜单（或 Shift+F10）执行操作。菜单提供返回主窗口、切换工作区、复制 API 地址、刷新或暂停采样、置顶和打开设置等操作。公共设置中的“监控浮动条”可调整默认置顶与采样时间显示，修改自动保存。Windows 上可从浮条右键菜单“收起到任务栏监控”：由任务栏监控接替显示实时读数，并记住到下次启动，在任务栏监控右键选“切换为桌面浮条”即可换回。系统托盘只保留一个普通应用图标，不显示读数。关闭浮条不影响主应用。具体外观见[浮条设置示例](screenshots/floating-monitor-settings.zh.webp)。

“快速测速”由浮条交给主窗口执行：仅在模型已就绪、推理与管理任务空闲时，串行运行短请求和解码两个场景。此操作会发送实际推理请求；日常监控采样仍只读已有后台，不会启动或恢复已停止的服务。右键菜单、置顶和系统剪贴板的实际桌面行为需单独验收，界面截图不替代这些验收。

历史边界：0.1.4 浮条的原生命令入口只允许读取监控和显示主窗口。0.1.5 增加的菜单、托盘与快速测速操作不属于 0.1.4 安装包。

状态查询失败时，界面停止使用旧进程数据授权操作；断联恢复后，指标需来自错误发生后的成功采样才恢复显示。正常后台轮询保留上次成功采样。

状态面板使用真实指标轮询结果，最多保留 60 点且只保留最近一次追加采样前 180 秒内的历史；图表保留采样间距和缺失点。生成与输入处理分开取样，空闲时的速度标明“最近生成”，不重复绘成新的吞吐样本。停止、断联隐藏实时指标；采集失败保留历史并标明暂停。PID 或启动身份变化会隔离 health/metrics 缓存和趋势。

已有记录包含 Windows MCP 启停、断开后继续运行、停止不自动恢复、模型恢复与短推理；配置哈希保持一致。隔离浏览器覆盖 Benchmark、调优、更新与下载界面，部分安装后桌面交互另有记录。这些界面与夹具证据不等于真实 GPU 性能测量。

发行构建、官网截图与链接、公开安装包签名和校验和按最终提交分别核验。真实 GPU Benchmark 测量、完整调优、GPU 长时压测、Linux 系统级 DEB 安装及客户端跨版本自动更新仍需独立验收；旧版或单台机器结果不代表全部硬件兼容性。
