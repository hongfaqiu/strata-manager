# 故障排查与反馈

[文档目录](README.md) · [使用指南](USER_GUIDE.md) · [下载与体验](DOWNLOAD.md) · [English](TROUBLESHOOTING.en.md)

本页对应当前源码，已发布 beta 以其版本说明为准。先确认问题发生在哪个阶段：Strata 安装或更新、模型准备、API 启动、模型加载、聊天、统计或调优。API 在线不等于模型已加载，空统计也不等于没有调用。

## 先检查这三处

1. **总览：** 查看当前选择的模型、模型可用性和后台健康状态。
2. **Strata、任务、调优与设置：** Strata 页查看运行环境版本、更新包和日志；任务页查看准备与更新错误；调优页查看测量报告；设置页查看应用更新。确认操作结束后再重试，避免同时进行多次维护。
3. **我的模型与运行配置：** 核对当前模型、配置标记、服务地址和安装目录，在模型内打开图形化/JSON 配置。接管问题按检测诊断处理，不仅凭端口判断进程归属。

## 模型准备与导入

| 现象 | 下一步 |
| --- | --- |
| 检测不到已有安装 | 在“我的模型”添加 Strata 搜索目录；在 Strata 页核对环境，按诊断检查源码、Python、配置、模型和 tokenizer |
| 模型已有权重却提示准备 | “我的模型”会直接展示发现的模型；先添加遗漏目录并检查配置。裸权重不一定包含可运行配置，环境缺失与权重缺失分别处理 |
| 磁盘预检显示不足、未知或错误 | 查看实际目标磁盘与路径，释放对应磁盘空间后刷新；预检未确认前不能准备新模型 |
| 下载或依赖准备失败 | 查看失败下载或依赖的日志，检查网络、代理与目标目录权限；处理原因后重试 |
| 存在多个配置 | 同一模型卡片下切换配置，核对路径、修改日期和当前/上次使用标记；仅查看配置不会切换运行服务 |
| 运行中实例无法接管 | 等待原请求结束并阅读身份诊断；身份不明或繁忙的进程不会被强行停止 |
| Linux 依赖或崩溃保护不可用 | 按提示检查 Python、venv、内核及系统限制；应用不执行 sudo 或绕过系统限制 |

已有模型导入不需要再次下载整套权重。新准备的空间估算不代表 RAM、VRAM、驱动和所有依赖都已就绪。

## 聊天与 API

| 现象 | 下一步 |
| --- | --- |
| API 在线，但聊天不可用 | 等待“模型可用”，查看加载任务、日志和内存；首次加载可能较慢 |
| 外部客户端连接失败 | 核对显示的本机地址、协议路径、密钥、模型状态与超时；部分客户端自身不能访问本机地址 |
| 图片无法添加或识别 | 确认当前服务报告图像支持；模型与视觉环境的能力需要分别核验 |
| MCP 没有工具或调用失败 | 检查服务器连接、可用工具与运行时支持；查看工具自身错误和联网配置 |
| 后台健康显示连续异常 | 阅读诊断，等待新检查或自行决定重试/停止；健康巡检不承诺强制修复卡死进程 |
| 关闭窗口后仍占显存 | 默认后台运行会保留模型；“释放模型内存”不删文件，托盘“停止服务并退出”结束受管服务。关闭后台运行选项后，关窗会确认退出 |
| 请求查看器不可用 | 按需在模型运行配置中开启 `api_monitor` 并重启；使用统计不依赖正文捕获 |

## 用量、调优与更新

| 现象 | 下一步 |
| --- | --- |
| 统计没有数据 | 检查当前服务是否由应用接管、观察器是否采集，以及所选时间范围 |
| 数据显示未知或断档 | 查看兼容性与采集范围；开始采集前或缺失的观测数据不能补写为完整历史 |
| CSV 超过 5,000 条 | 缩小时间范围或筛选条件再导出；取消系统保存对话框不会生成文件 |
| 调优提示繁忙或无收益 | 先结束聊天与外部请求，检查完整用途场景的质量、资源和基线漂移；无可重复收益时保持当前配置 |
| 重启候选被拒绝 | 检查能力与资源诊断、启动观测和原配置；显存预留只能增加已知值，不把未知生效状态视为支持 |
| 调优应用或更新恢复失败 | 保留任务与诊断，处理配置、环境或加载原因后重试；不能假设旧服务已经恢复 |
| 应用更新检查/下载失败 | 检查网络和正式发布状态，保持当前版本后重试；更新日志确认前不会自动安装 |
| Strata 更新不可用 | 在 Strata 页检查官方发布、匹配 ZIP、依赖与配置诊断；缺少平台包时保留现有安装 |
| ZIP 下载、解包或替换失败 | 保留任务日志并处理校验、路径、权限或进程归属原因；若恢复失败，按诊断修复后重试，不假设服务已经恢复 |

自动恢复只针对所选受管服务退出后的有限尝试，不代表每次 API 异常、更新失败或硬件故障都能自行解决。操作范围和详细限制见[使用指南](USER_GUIDE.md)。

## 反馈问题

先查看[已有 Issues](https://github.com/hongfaqiu/strata-manager/issues)是否有相同问题；没有相关记录时，打开[问题反馈表](https://github.com/hongfaqiu/strata-manager/issues/new?template=bug_report.yml)填写：

- 系统版本、应用版本或源码提交，以及安装包/源码来源。
- Strata 运行时与模型标识，相关 GPU、RAM/VRAM 信息。
- 从哪一步开始、预期行为、实际结果，以及可重复的最少操作。
- 任务或健康状态中的错误，以及必要的脱敏日志片段或截图。

选中模型后，在“监控 → 任务”点击“导出诊断”；也可从模型详情的日志入口进入任务页。分享前检查内容，移除密钥、私人路径、个人聊天、附件和工具参数；用量元数据与请求正文诊断是不同内容。
