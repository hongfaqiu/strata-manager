# Strata Manager 使用指南

[返回产品介绍](../README.md) · [English](USER_GUIDE.en.md) · [当前验收范围](VERIFICATION.md)

Strata Manager 只管理它安装或导入的本机 Strata。服务地址、Python 环境、启动和加载由后台维护，普通使用不需要手动执行启动脚本。

## 第一次使用

### 已经有 Strata 或模型

1. 打开“模型”，检查“我的模型”。旧版 Manager 的有效模型档案与聊天记录会自动恢复。
2. 首次使用时查看检测结果，选中已有安装并导入。检测遗漏时选择 Strata 文件夹即可。
3. 点击“使用”，等待模型可用，再进入聊天。原有模型保持原位，原配置保留，应用使用受管副本。

已下载的模型不需要再下载。检测到由其它程序运行的实例时，应用先核验来源与活动状态；身份不明或正在处理请求的进程不会被强制停止。如果无法接管，查看提示和日志后再处理。

### 还没有安装

1. 使用准备向导，应用下载并校验固定版本的官方源码，创建私有运行环境。
2. 按用途、本机容量和上游要求选择模型、量化、上下文和图像能力。
3. 在任务中查看下载与准备进度。命令成功且资产核验通过后，模型自动加入列表；多份配置有歧义时按提示选择。
4. 点击“使用”。应用检查环境、启动服务并加载模型。

准备新模型不会自动替换当前选择。失败可以重试，也可以取消；权重较大时首次准备会需要较长时间。

Windows 检测 64 位 Python 3.10+；未找到时提供经 SHA256 校验的官方 Python 私有安装路径。Linux 需要 Python 3.10+、venv 和 ensurepip；缺失依赖会给出提示，应用不执行 sudo。缺 Python 的完整安装分支仍待干净机器验收。

## 日常使用

| 页面 | 可以做什么 |
| --- | --- |
| 总览 | 查看模型可用性、后台状态、用量、资源和下一步操作 |
| 模型 | 检测导入、准备模型、查看任务、选择当前使用的模型 |
| 聊天 | 管理多个会话、流式回答、文本/图片附件、思考与 MCP 事件 |
| 调优 | 选择场景、测量候选、比较结果、应用或恢复 |
| 监控 | API 用量、官方性能监控、按需请求正文诊断和日志 |
| 设置 | 语言、主题、后台策略、登录自启动、更新与运行配置 |

关闭窗口后，独立后台继续提供已经启动的 API。关闭窗口、退出界面和停止服务是不同操作；需要释放模型并结束受管服务时，使用托盘“停止服务并退出”。重新打开应用会连接同一用户已有的后台。

默认后台轻量运行，模型按需加载；希望首次请求更快进入服务时，可以选择提前加载。登录自启动启动后台，不先打开聊天窗口。真实注销/重登流程的验收仍待完成。

## 接入本机 API

先确认模型可用，再查看总览或模型页显示的本机服务地址。把客户端所需的 Base URL/API 路径配置为对应地址，不需要创建远程服务档案。

Strata 提供 Chat Completions、Responses 与 Anthropic Messages 等协议；具体支持以当前运行时为准。客户端要求 OpenAI Base URL 时使用对应的 `/v1` 地址，而不是聊天页面的网址。配置了 API Key 时，客户端也要使用同一密钥。

首次加载大型模型可能需要较长时间，客户端超时要匹配实际加载时间。连接失败时依次检查模型状态、显示的端口、API 路径、密钥和日志。

## 阅读 API 用量

在“监控 → API 用量”选择今日、最近 24 小时或最近 7 天，可以查看请求趋势、成功率、失败/取消/中断、输入输出 tokens、缓存、首个输出等待时间、总耗时、解码速度、MCP 调用和最近请求。

今日按本机时区计算。元数据保留 90 天，后台持续采集；关闭监控页面不会停止采集。

HTTP 请求、模型推理轮次和工具调用分别计数。一次 MCP 请求可能有多轮推理，token-count 请求只计 HTTP 请求；HTTP usage 与推理工作量不能相加当作总 token 用量。成功率排除未结束请求。

缺失值显示未知，不等于零。请同时检查采集状态、兼容性与断档；开始采集前的时间不代表完整统计。客户端没有可识别标签时显示为未知来源。

## 数据与隐私

聊天历史保存在本机。API 使用统计只保存请求与推理元数据，不保存提示词、回答、思考、附件、工具参数或 API 密钥。

官方 API Monitor 的请求正文捕获是独立诊断功能；导入的原配置可能已开启它。按需检查该设置，元数据统计不要求开启正文捕获。

模型推理在本机，运行环境、模型与更新下载需要网络。MCP 工具按用户配置执行，可能访问外部服务；请根据自己的工具配置判断其行为。报告问题或分享诊断前，移除密钥、私人路径和聊天内容。

## 参数调优

选择用途后启动比较，应用按“当前配置 A → 候选 B → 恢复 A”测量有限候选，区分新提示和立即重复前缀的表现。报告包含耗时、首个输出等待时间、速度、缓存与输出一致性。

推荐要求收益超过当轮基线波动，并且确定性测试输出完整一致；结果不稳定时保留原配置。这验证一致性和流程，不替代完整 Agent、语义质量、视觉、长上下文或冷加载测试。当前自动调优针对有限请求级参数；上下文、KV 和启动配置仍需结合容量及质量检查。

采用结果会保存恢复记录、重启受管服务并检查加载；失败时恢复原配置。应用期间本机 API 会短暂受影响，请避免并行维护。实际 GPU 收益以模型、硬件和测试报告为准，演示截图不代表性能结果。

## 应用更新

在设置中检查更新。正式更新使用内置公钥验证 Tauri 签名；应用、Strata 运行环境和模型权重分别管理，应用更新不会以重新下载模型作为正常流程。

当前首版正式安装包尚未发布，跨版本签名下载安装仍待实际验收。Tauri 更新签名与 Windows 发布者代码签名不同，本项目目前没有 Windows Authenticode 发布者证书。安装、后台版本切换和模型/API 恢复分别记录在[验收记录](VERIFICATION.md)。

## 遇到问题

| 现象 | 建议 |
| --- | --- |
| 找不到已有安装 | 选择 Strata 文件夹，检查源码、Python、配置及模型文件的诊断 |
| API 启动了，模型还不能聊天 | 等待模型加载，查看任务和日志；API 在线与模型可用是两个阶段 |
| 客户端连接失败 | 检查本机地址、路径、模型状态、超时与密钥 |
| 统计为空或未知 | 查看采集状态、兼容性和断档；旧版或改动过的运行时可能不支持完整观测 |
| 调优没有提速 | 保留原配置，用实际工作负载复验，不把缓存命中等同完整任务提速 |

问题反馈请前往 [GitHub Issues](https://github.com/hongfaqiu/strata-manager/issues)，说明系统、应用版本、操作步骤和脱敏后的错误信息。
