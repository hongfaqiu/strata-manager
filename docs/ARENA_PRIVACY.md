# Benchmark 排行榜隐私说明

Benchmark 排行榜是可选功能。不加入时，Benchmark 测试照常运行，结果只保存在本机。

## 什么时候上传

在 Strata Manager「Benchmark → 排行榜」中同意后，每次 Benchmark 完成都会自动上传一次结果。上传前会在同意页逐字展示将上传的内容。自动上传可以随时关闭；关闭时，尚未上传的结果会一并丢弃。

## 会上传的内容

| 类别 | 字段 |
| --- | --- |
| 硬件 | GPU 厂商、型号与显存，CPU 型号，内存总量，PCIe 代数与通道，操作系统类型与架构，是否 WSL |
| 模型 | 模型系列、量化、由模型文件名与大小计算的指纹、模型大小 |
| 启动参数 | 上下文长度、KV 缓存类型、GPU 数量、并行数、线程数、专家缓存、PCIe 比例、是否启用视觉 |
| 结果 | 每个上下文档位的预填充与解码速度、首字时间、峰值显存与内存、是否成功；场景测试只上传汇总速度与请求数 |
| 版本 | Strata Manager 与 Strata 版本、授权版本 |
| 本机公钥 | 加入时本机随机生成的 Ed25519 公钥（只在注册时上传一次） |

所有字段由应用按固定白名单构建，文字字段只允许字母、数字与少量标点，上传前在本机与服务器两端各校验一次。

## 不会上传的内容

文件路径、电脑名、用户名、API 密钥、服务地址、提示词、回答内容和日志都不会上传。

## 本机密钥与 IP

加入时，应用在本机随机生成一对 Ed25519 密钥。私钥保存在系统凭据库中（不可用时保存在应用数据目录中仅当前用户可读的文件里），从不上传。公钥在首次上传前注册一次，注册时本机需要完成几秒钟的计算（工作量证明），用来提高批量伪造机器的成本。之后每次上传和删除都用私钥签名，服务器只认这把公钥，不再使用其他安装标识。

公钥与你的身份、电脑名或账号无关，只用于把同一台机器的多次结果合并成一个中位数、核对结果是否可信，以及让你删除自己的数据。服务器为每把公钥保存注册时间、最近上传时间、上传次数和一个可信度评分。

服务器不保存 IP 地址。为了限流，服务器把 IP 与当天日期一起做带密钥的哈希，只保存截断后的结果，两天后删除。

## 新机器与可信度

新注册的机器先处于待验证状态：结果会保存，但暂不计入排行榜。在至少 2 天内上传 3 次、且与同模型、同量化、同硬件和参数的其他机器结果一致（或得到其他机器印证）后，才计入排名。与同配置机器差距过大、或首字时间与预填充速度明显矛盾的结果会被标记，不进入统计。维护者可以隐藏单条结果，或停用某把公钥的上传。

## 保留期限与删除

结果保留 12 个月，之后自动删除。点击「撤回并删除我的数据」会立即删除服务器上这台机器上传的全部结果，删除这台机器的公钥注册，并清除本机的私钥与待上传队列。再次加入会生成新的密钥，与之前的数据无关。被停用的公钥撤回后只保留公钥摘要和停用标记，用于阻止它再次注册。结果和长期未上传的公钥注册都在 12 个月后自动删除。

## 排行榜如何使用数据

排行榜只在同一模型、同一量化内比较，按硬件与启动参数分组。只使用已通过验证的机器，每台机器取最近 3 次的中位数，剔除离群值，同一配置至少 3 台机器才排名。维护者实测的结果会单独标注。应用与官网只展示汇总结果，不展示单台机器的数据。

服务地址：`https://arena.cosfoc.com`，运行在 Cloudflare Workers 与 D1 上。
