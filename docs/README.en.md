# Strata Manager documentation

[Website](https://hongfaqiu.github.io/strata-manager/?lang=en) · [Product overview](../README.md) · [简体中文](README.md)

Local models. One workspace. Strata Manager brings model import and preparation, configurations, conversations, background services, monitoring and a local API into one desktop app. Available models and protocols depend on your installed Strata runtime and chosen model.

## Supported scope

- Manage supported Strata installations prepared or imported on this computer. Existing weights stay in place.
- Image input, reasoning, MCP tools and API protocols depend on the runtime, model and tool configuration.
- Tuning compares supported PCIe budget and MTP speculation parameters; it does not promise a fixed speedup.
- Current targets are Windows/Linux x64. Release packages, GPU use, real Linux systems and cross-version updates are verified separately. Screenshots and controlled fixtures do not establish real-model acceptance.
