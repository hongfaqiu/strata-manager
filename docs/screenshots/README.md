# 界面截图 / Screenshots

20 张界面截图于 2026-10-11 从已发布的 Strata Manager 0.1.2 源码（提交 `2fac51edd7147526442ddbb109a6a28d7b276ef7`）生成。中文和英文均使用亮色主题，涵盖总览、Strata、模型、运行配置、聊天、API 使用统计、调优、监控、设置和关于。

界面由实际 App 组件渲染。模型、配置、聊天、硬件、版本、状态和统计使用隔离的内存示例数据；截图没有操作真实模型服务，也没有进行推理、安装、更新或性能测量。这些示例数值不是性能测试结果。

浏览器视口为 1440 × 960 CSS 像素，设备像素比为 2，原始 PNG 为 2880 × 1920 像素。截图转为无损 WebP，并逐像素确认与原始 PNG 一致，未缩放、重绘或修改界面内容。每张图片的尺寸、主题、SHA-256 和原始 PNG 校验值见 [manifest.json](manifest.json)。

`product-cover.webp` 是单独设计的产品 Hero 图，使用真实的亮色界面截图进行产品展示；它不是未经修改的 Strata 页面截图。界面截图与 Hero 的来源分别记录，不将封面与某个页面文件视为同一图片。

The 20 UI screenshots were captured on 2026-10-11 from the published Strata Manager 0.1.2 source at commit `2fac51edd7147526442ddbb109a6a28d7b276ef7`. Both Chinese and English use the light theme, covering Overview, Strata, Models, Configuration, Chat, API usage, Tuning, Monitoring, Settings and About.

The real App components render isolated in-memory documentation examples for models, configuration, conversations, hardware, versions, status and statistics. No real model service was operated, and no inference, installation, update or performance measurement was performed. The example numbers are not benchmark results.

The browser viewport is 1440 × 960 CSS pixels at a device pixel ratio of 2, producing 2880 × 1920 PNGs. Lossless WebP conversion is checked pixel by pixel against each original PNG, with no resizing, redrawing or alteration of the UI. Dimensions, theme, SHA-256 and source PNG hashes are recorded in [manifest.json](manifest.json).

`product-cover.webp` is a separately designed product hero using the real light-theme UI screenshots. It is not an unmodified Strata-page screenshot. UI capture provenance and hero composition provenance are recorded separately.
