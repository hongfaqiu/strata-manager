02 / 日常使用，更顺手

少一些准备，多一些从容。

为 Strata 支持的模型提供本机桌面工作台。继续使用已有的文件，也看清服务正在做什么。

展开使用指南
01

已有模型，继续使用。

检测并导入本机 Strata。原有权重保持原位，应用使用受管配置副本；需要新模型时，再走准备向导。

02

聊天，把上下文放在身边。

多会话、流式回答、思考过程、文本和图片附件，以及 MCP 工具事件集中展示。实际能力取决于运行时与模型。

03

关闭窗口，API 继续运行。

独立后台管理已启动的服务。重新打开界面即可连接回来；需要释放模型时，从托盘停止受管服务。

04

知道模型是怎么被使用的。

查看请求、tokens、成功率、等待时间、缓存和最近活动。用量统计保存元数据，缺失值会明确显示未知。

05

调优，先比较再决定。

比较基线与有限候选参数，查看一致性和波动，再决定应用或恢复。没有稳定收益时，保留当前配置。

03 / 开始你的工作流

三步，开始使用。

启动和加载由应用处理。从你的模型开始，再选择适合自己的使用方式。

  1. 1

    找到你的模型。

    打开“模型”，恢复旧版有效档案，或导入已有 Strata。还没有安装时，使用准备向导。

  2. 2

    点击“使用”，等待可用。

    后台检查环境、启动 Strata 并加载模型。通过任务日志查看准备进度，等待“模型可用”。

  3. 3

    开始聊天，或连接工具。

    进入聊天发送消息，或把界面显示的本机 API 地址配置到客户端。协议能力以当前运行时为准。

关于模型、后台服务和本机数据的几个实际问题。

可以使用哪些模型？+

Strata Manager 管理在这台电脑上准备或导入的、Strata 支持的模型。模型、图像和 API 能力取决于已安装的运行时与所选模型，准备前请查看上游要求。

查看 Strata 说明 →
已有模型，需要重新下载吗？+

不需要。导入已有的本机 Strata，或恢复旧版 Manager 的有效档案。模型文件保持原位，仅在选择准备新模型时下载新权重。

关闭窗口后，服务会停止吗？+

已启动的服务由独立后台继续提供。重新打开应用即可连接回来；需要释放模型并停止受管服务时，使用托盘的“停止服务并退出”。

聊天记录和用量数据保存在哪里？+

聊天历史保存在本机。用量统计保存元数据，不保存提示词、回答、附件或 API 密钥。请求正文捕获是独立诊断设置；下载、更新及配置的 MCP 工具可能访问网络。

调优一定能让模型更快吗？+

收益取决于模型、硬件和实际工作负载。应用比较有限的请求级参数，并报告一致性和波动。提升不稳定时保留当前设置；截图中的数值是演示数据。
