你能管理什么

先扫一眼标题，再展开查看截图与说明；同一时间只打开一个面板。

  • 检测已有安装，选择官方 GitHub、HTTPS 镜像或本地 ZIP，安装前核验长度与 SHA256。
  • 发现本机模型权重，用图形控件或 JSON 编辑运行设置，并保留配置备份。
  • 下载时可勾选显卡编号，并快捷设置 batch、parallel 等常用启动参数。

  • 控制服务启停与内存释放；需要时可保存和恢复引擎会话。
  • 在 Windows 上查看运行中服务，连接已有 Manager 后台，或在核验空闲后托管外部服务。
  • 空闲释放后再次请求时，状态栏显示自动载入进度与耗时。

  • 管理会话、添加附件并阅读流式回复，使用结构化输出与受支持的工具。
  • 新模型默认继承公共生成参数与 MCP 开关；专用值保持独立，更改在下一次请求生效。

  • 选择连接目标、保存应用访问密钥，复制 API 或 MCP 接入配置。
  • 提供 Cursor / Codex 等接入向导；选择目标不会自动启动或切换模型。
  • 可显式做限时限量的文本、工具结构或图片在线验证。

  • 查看硬件指标、API 用量和近期生成 / 输入处理趋势，并保留缺失点。
  • 独立桌面监控浮条默认关闭：可选布局、字号、指标排序与配色，不影响后台或模型启动。

  • 按聊天、编程 / Agent 与长文任务比较受支持的参数候选，再决定是否应用。
  • 在模型核验上限内按上下文档位或七类场景串行测试，对比预填充、解码与资源占用。
  • 结果支持复制图片与 PNG、JSON / CSV 导出；弱身份或未知条件不宣称直接提速。

  • 可跟随系统或选择内置语言包，并设置亮暗外观与托盘行为。
  • 独立更新页提供随包双语日志、稳定更新检查和 Tauri 签名安装确认。

工作流程

准备、运行、观测。展开任一步查看配图说明。

    • 从官方、镜像或本地包安装 Strata，替换文件前完成核验。
    • 指向本机权重，并保留一份可启动的校验配置。

    • 启动所选配置，使用带附件的流式聊天，并按需继承公共生成默认值。
    • 外部助手需要接入时，在桌面内复制 API 或 MCP 客户端配置。

    • 在服务由 Manager 管理时跟踪 GPU、内存、CPU 与近期生成趋势。
    • 需要可比证据时再运行 Benchmark 或调优，再决定是否改配置。
