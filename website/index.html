01Strata 是什么？跟 Manager 什么关系？

Strata 是 Niko1221 维护的开源本地推理引擎，负责把模型分摊到显存、内存和 CPU 上跑起来，再提供一个浏览器界面和本机 API。

Manager 不做推理，也不是官方项目。它是社区做的一层外壳：帮你装 Strata、改配置、看日志、看数字。引擎和模型都要另外装。

02具体管哪些事？

大致按你会碰到的顺序排。你装的 Strata 不支持的功能，这里也不会硬给。

  1. 01装引擎先找已有的安装；没有就下 ZIP，断了能续，下完对一遍 SHA256。
  2. 02管模型扫出硬盘上的权重，看 GGUF 信息和各占多少空间。
  3. 03起服务改配置（会留备份），启动、停止、重启、释放显存，看日志。
  4. 04聊天、接入自带一个聊天窗口；给外部工具配 API 和 MCP。
  5. 05看负载槽位、显存、温度。想常驻桌面就开浮条，默认关着。
  6. 06看用量请求数、Token、延迟、缓存命中；调参前后能对比。
  7. 07跑分按上下文长度或七种场景一个个跑，结果能导出 CSV 和 PNG。
  8. 08更新应用、Strata、模型分开更新，互不牵连。

03已经下好的模型，要重下或者挪地方吗？

不用。权重放哪儿还放哪儿，Manager 只是去读。装 Manager 本身也不会偷偷下模型——几十 GB 的东西，还是你自己决定。

04用量统计会存我的对话吗？

不存。记的是请求数、Token、耗时、缓存命中这些数字，请求正文不记。排查问题时可以临时打开正文诊断，那是单独的开关，得你手动开，记了什么写在使用指南里。

05怎么让 Cursor、Codex、Cherry Studio 用上本地模型？

打开「API 与外部助手」，复制地址（一般是 http://127.0.0.1:19001/v1），要密钥就设一个，再照对应工具的示例填。选目标只是选目标，不会顺手把模型拉起来或换掉。

填之前可以先点一下「API 在线验证」：查服务身份、拉模型列表、发一条限量请求，正文和密钥都不留。总比在编辑器里对着 401 发呆强。

06设置点了保存，就算生效了吗？

不一定。保存只说明写进了配置，正在跑的引擎认没认是另一回事。Manager 拿不到证据时就标「未核验」，要重启才生效的选项会单独提示。模型没就绪，它也不会为了验证去偷偷启动。
