常见疑问解答

关于模型、后台与隐私的常见问答。

解答关于环境安装、模型导入、显存释放与数据隐私的常见疑问。

在 GitHub 提交反馈
可以使用哪些模型？需要特定的格式吗？

支持所选 Strata 运行时兼容的常见模型系列与量化格式。“我的模型”可自动扫描本机模型，亦提供内置下载目录便捷准备新模型。

电脑里已经有下载好的模型，需要重新下载吗？

无需重复下载。已有的受支持权重保持原路径即可自动扫描，支持添加外部目录；多套运行配置可共享同一份权重文件。

关闭桌面窗口后，后台服务会中断吗？显存如何释放？

默认关闭到托盘，已启动的服务继续运行。“释放内存”卸载当前模型并保留文件与 API 进程，实际占用以监控为准；需要退出时从托盘选择“停止服务并退出”。

聊天记录和用量统计保存在哪里？是否有网络外泄？

聊天与用量元数据保存在本机；运行环境、模型下载和更新需要网络。配置的 MCP 工具可能访问外部服务或发送数据，启用前请检查工具行为。

参数调优真的能让模型变快吗？它的原理是什么？

比较所选对话、编程与长文任务，检查质量和资源后再应用参数。收益取决于实际模型与硬件，没有固定提速保证；截图数值是示例。

Strata 更新会自动安装吗？

先查看日志并确认，匹配的官方 Windows x64 ZIP 才下载、解包并更新程序文件，保留模型与备份。Linux 可查看发布与日志，不提供 Windows 引擎 ZIP 更新。
