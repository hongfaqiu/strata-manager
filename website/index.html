Strata Manager · 开源桌面管理工具

本地大模型的管理与监控。

Strata 是一款开源的本地大模型推理引擎，利用 CPU 与 GPU 协同运行模型。Strata Manager 将环境准备、模型与服务、公共聊天设置、API/MCP 接入、监控和性能评估集中到同一桌面工作台。

Strata 与 Manager如何协作

Strata · 推理引擎
加载受支持的模型权重，协调 CPU 与 GPU 执行推理，并通过本地 API 为聊天应用与开发工具提供服务。
Strata Manager · 桌面管理工具
管理运行环境、模型配置和服务生命周期，提供聊天、硬件监控、API 用量、参数调优、Benchmark，以及 Cursor／Codex 等接入向导。

日常能做的事。

装引擎、跑模型、看机器、调参数、做测速。

01

环境与 Strata 更新

检测已有安装，校验配置并保留备份；Windows 引擎 ZIP 可走官方 GitHub、镜像或本地包。环境页也能在跟踪文件干净时，用官方脚本更新 Strata。

02

模型与服务

在下载列表选模型，详情里一次选好显卡、上下文、KV 和槽位；启停服务时资源评估跟着当前选择变。未知项就标未知，不会拿缺证据硬说容量。

03

公共聊天与 API / MCP

流式聊天和附件，公共生成参数可按模型继承或保留专用值。在“API 与外部助手”里配连接目标、密钥和 MCP；向导带 Cursor、Codex 示例，选目标不会启动模型。

04

资源监控与桌面浮条

硬件、API 用量，以及生成／输入处理的近期趋势都会留着缺失点。桌面浮条默认关掉，三种布局、指标排序和配色可调；打开它也不会为了采样去启动后台。

05

按任务调参

按聊天、编程／Agent、长文任务比较受支持的参数；看质量、速度和占用后再应用或恢复，不保证固定提速。

06

Benchmark 与历史对照

在核验上限内跑上下文档位，或串行七类场景。升级前可留基线对照条件；身份弱就不下直接提速结论。支持 PNG、JSON／CSV 导出。
