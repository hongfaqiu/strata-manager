Strata Manager · 开源桌面管理工具

本地大模型的管理与监控。

Strata 是一款开源的本地大模型推理引擎，利用 CPU 与 GPU 协同运行模型。Strata Manager 把它装进一个桌面工作台：首次上手引导、模型下载与多版本配置、服务启停、API 验证与用量、Agent 接入、监控调优，以及共享的 Benchmark 排行榜。

Strata 与 Manager如何协作

Strata · 推理引擎
加载受支持的模型权重，协调 CPU 与 GPU 执行推理，并通过本地 API 为聊天应用与开发工具提供服务。
Strata Manager · 桌面管理工具
管理运行环境、跨 Strata 版本的模型配置和服务生命周期，提供聊天、API 在线验证、用量统计、硬件监控、参数调优、可选上传的 Benchmark 排行榜，以及 Cursor、Codex、Claude Code 等接入向导。

日常能做的事。

从第一次安装到日常调用：装引擎、管模型、接 API、看用量、调参数、比速度。

01

上手与 Strata 环境

“开始使用”从检查环境、安装 Strata 一路带到下载模型、加载和第一次聊天。已有安装会被识别；Windows 引擎 ZIP 可走官方 GitHub、镜像或本地包，并按大小和 SHA256 校验。

02

模型与多版本配置

按本机显存与内存挑模型和量化，一次选好显卡、上下文、KV 和槽位，看清每份配置要多少资源。多个 Strata 版本共用一份权重时，配置按版本标注，相同副本合并，旧版本可以清理也能恢复。

03

API、MCP 与 Agent 接入

复制本机地址，按向导接入 Cursor、Codex、Claude Code、Cherry Studio 等客户端。在线验证逐步检查服务身份、模型、能力和一次测试请求，每步都有状态和耗时；公共聊天参数与 MCP 集中配置。

04

用量与监控

用量面板先给出请求、成功率、失败、Token 和生成速度，再展开趋势、调用来源、请求结果、延迟与缓存复用，统计不抓请求正文。硬件与服务趋势保留采样缺口；桌面浮条默认关闭，需要时再开。

05

按任务调参

按聊天、编程／Agent、长文任务比较受支持的参数；看质量、速度和占用后再应用或恢复，不保证固定提速。

06

Benchmark 与排行榜

在核验上限内跑上下文档位或串行七类场景，留存历史并对照条件，身份不足就不下提速结论。同意后可匿名分享结果，在公开排行榜上按同模型、同量化对比不同硬件。
