Strata Manager · 开源桌面管理工具

本地大模型的管理与监控。

Strata 是一款开源的本地大模型推理引擎，利用 CPU 与 GPU 协同运行模型。Strata Manager 将环境准备、模型与服务、公共聊天设置、API/MCP 接入、监控和性能评估集中到同一桌面工作台。

Strata 与 Manager如何协作

Strata · 推理引擎
加载受支持的模型权重，协调 CPU 与 GPU 执行推理，并通过本地 API 为聊天应用与开发工具提供服务。
Strata Manager · 桌面管理工具
管理运行环境、模型配置和服务生命周期，提供聊天、硬件监控、API 用量统计、参数调优与基准测试。

覆盖本地推理的
日常管理流程。

准备环境，运行模型，观测与评估。

01

环境安装与配置

检测已有安装，校验配置并保留备份。Windows 引擎 ZIP 默认使用官方 GitHub，支持保存镜像与断点续传，各来源按当前 CUDA12、CUDA13 或 HIP 引擎匹配。

02

模型与服务管理

发现本机权重，按模型管理配置，控制服务启停与内存释放；保存和恢复引擎会话，查看各槽位的请求负载。

03

聊天与应用接入

使用流式聊天与附件，按模型继承公共生成参数或保留专用值；在“API 与外部助手”集中配置连接目标、访问密钥、API 示例与 MCP。

04

资源与 API 监控

查看硬件、API 用量和近期生成/输入处理趋势，明确保留缺失点。独立桌面监控浮条默认关闭，可按需打开，不会启动后台或模型。

05

面向任务的参数调优

按聊天、编程 / Agent 和长文任务比较受支持的参数候选，结合响应质量、速度与资源占用选择配置，支持应用或恢复。

06

Benchmark 基准测试

在模型核验上限内按上下文档位测试，或串行运行七类场景；对比预填充、解码、延迟和资源趋势，支持复制结果图片与 PNG、JSON / CSV 导出。
