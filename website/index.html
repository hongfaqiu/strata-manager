Strata Manager开源 · MITWindows · Linux x64

给 Strata 配一个桌面管理器。

Niko1221/Strata 的开源桌面程序。装引擎、整理模型、起停服务，顺便看清本机 API 和显卡在干嘛。已经下好的模型不用挪。

下载 Windows 版x64 · .exe 下载 Linux 版x64 · AppImage

安装包在 GitHub Releases 上，附 SHA256SUMS。

三方各管什么

Strata 运行时Niko1221/Strata加载模型、做推理、提供 API。支持哪些模型、能不能传图，看你装的引擎和模型。
Strata Manager本项目装引擎、管模型和配置、起停服务，外加聊天、监控、调参和跑分。自己不做推理。
你的应用Cherry Studio、Cursor、Codex …服务起来以后，连本机 API 用模型。

从装上到天天用

你装的 Strata 不支持的功能，这里也不会硬给。

No.流程能做什么平台界面
01装引擎先找已有的安装，顺便对比本机和上游版本。没有就下引擎 ZIP，来源可以是官方 GitHub、代理、自定义 HTTPS 或本地文件；断了能续，下完按官方大小和 SHA256 校验。Windows：下载、续传
Linux：扫描、看日志
02管模型扫出硬盘上的权重，同一个模型的运行配置归到一起。下载时选来源和显卡；模型文件、GGUF 元数据、占了多少盘都看得到。Windows · Linux
03起服务用表单或者直接改 JSON，保存前会校验并留备份。启动、停止、重启、释放内存；启动卡在哪一步、日志说了什么都看得到。Windows · Linux
接管运行中的服务：仅 Windows
04聊天、接入自带流式聊天，支持附件和结构化输出。外部工具的地址、密钥、API 示例和 MCP 都在「API 与外部助手」里配；选目标不会顺手启动或切换模型。Windows · Linux
05看负载保存和恢复引擎会话，看槽位、负载和硬件。只看不碰：打开监控不会把服务拉起来。桌面浮条和托盘监控可选，默认关着。Windows · Linux
06看用量、调参记录本机 API 的请求、Token、延迟和缓存复用，只记数字不记正文。按聊天、写代码、长文三类比较调参候选，看满意了再应用。Windows · Linux
07跑分按上下文档位或七种场景一个个串行跑，记下 Token、输入处理和生成速度、首 Token 延迟、资源占用。历史能翻，能导出 JSON / CSV / PNG。Windows · Linux
08更新与设置应用、Strata、模型权重分开更新；更新日志随包带中英文，安装包用 Tauri 签名校验。十种界面语言，亮色暗色都有。Windows · Linux

各部分怎么配合、数据存在哪儿，写在系统说明里。

下载

安装包里是桌面程序加一个后台进程。Strata 引擎和模型要另外装。

平台安装包装之前
Windows x64NSIS 安装包 · _x64-setup.exe需要 WebView2。没有代码签名证书，SmartScreen 多半会拦一下，确认文件来自本项目发布页就行。下载 .exe
Linux x64AppImage · .deb在 Ubuntu 22.04 上构建。AppImage 加上执行权限就能跑，.deb 用系统的软件安装器打开。AppImage.deb

SHA256SUMS全部发布安装步骤从源码跑：pnpm install --frozen-lockfile && pnpm desktop
