3 步开始 · 无缝集成

三步上手，融入已有工作流。

导入模型，启动服务，再开始聊天或接入可访问本机地址、支持相应协议的 API 客户端。

01

1. 扫描并选定模型

打开“模型”页，检测本机 Strata 安装，也可手动导入或通过向导准备新模型。原有权重原地复用。

02

2. 一键点击使用

点击“使用”，后台检查运行环境、启动运行时并加载模型。等待“模型可用”后开始使用。

03

3. 聊天或接入生态

在应用内聊天，或把显示的本机 API 地址接入兼容客户端或脚本。协议支持范围取决于运行时。

cURL / Terminal 
curl http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "current-model",
    "messages": [{"role": "user", "content": "Explain local LLM orchestration in Strata Manager"}],
    "stream": true
  }'

示例适用于支持 Chat Completions 的运行时。请使用实际服务地址与模型标识；启用 API 鉴权时，还需添加 Authorization 请求头。

常见疑问解答

关于模型、后台与隐私的常见问答。

梳理了你在日常安装、服务常驻与隐私考量中最常关心的问题。

在 GitHub 提交反馈
可以使用哪些模型？需要特定的格式吗？

可以导入受支持的本机 Strata 安装，或从准备向导的模型目录中选择。可用模型系列、格式、上下文长度与图像输入能力取决于已安装的运行时和具体模型；准备权重前请查看相应运行时要求。

电脑里已经有下载好的模型，需要重新下载吗？

可导入的已有 Strata 模型无需再次下载权重。导入其安装目录，或恢复旧版 Manager 的有效档案；权重保持原位，应用保存受管配置副本。

关闭桌面窗口后，后台服务会中断吗？显存如何释放？

关闭主窗口后，已启动的受管服务继续运行，重新打开应用可以连接回来。需要结束这些服务并释放其占用资源时，在系统托盘中选择“停止服务并退出”。

聊天记录和用量统计保存在哪里？是否有网络外泄？

聊天历史保存在本机。用量统计保存技术元数据，与聊天存储及可选的请求正文诊断分开管理。模型下载和更新需要网络；MCP 工具按你的配置运行，详见使用指南。

参数调优真的能让模型变快吗？它的原理是什么？

收益取决于模型、硬件和场景。当前调优比较有限的 PCIe 预算与 MTP 推测参数，通过“基线 → 候选 → 基线”检查漂移与输出一致性；不是自动搜索所有配置，也不保证提速。
