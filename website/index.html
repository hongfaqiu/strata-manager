Strata Manager · 开源桌面管理工具

本地大模型的管理与监控。

Strata 是一款开源的本地大模型推理引擎，利用 CPU 与 GPU 协同运行模型。Strata Manager 提供配套桌面界面，集中完成环境安装、模型配置、服务启停与运行监控。

Strata 与 Manager如何协作

Strata · 推理引擎
加载受支持的模型权重，协调 CPU 与 GPU 执行推理，并通过本地 API 为聊天应用与开发工具提供服务。
Strata Manager · 桌面管理工具
管理 Strata 环境、模型配置和服务生命周期，提供硬件资源监控与 API 用量统计。
