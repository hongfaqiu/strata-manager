日常能做的事。

从第一次安装到日常调用：装引擎、管模型、接 API、看用量、调参数、比速度。

01

上手与 Strata 环境

“开始使用”从检查环境、安装 Strata 一路带到下载模型、加载和第一次聊天。已有安装会被识别；Windows 引擎 ZIP 可走官方 GitHub、镜像或本地包，并按大小和固定哈希校验。从 Strata 0.2.0 起，Windows 和 Linux 都能按检测到的显卡一键安装签名引擎包，新引擎先试启动，失败自动回滚。可以指定 Strata 版本升级或降级，也能固定在当前版本；引擎和模型可放到其他盘。macOS 和 Linux 上 Python 版本不够时，可一键安装应用自用的 Python 3.12。Apple Silicon 上能识别显卡与统一内存，使用原生窗口按钮和菜单栏，并可在应用内安装上游预编译 Metal 引擎（预览，Metal 推理尚未完成真机验收）。Windows 上只有 AMD 显卡时会自动选对应的 HIP 引擎包；macOS 和 Linux 安装 Strata 时会一并装好 Python 依赖。

02

模型与多版本配置

按本机显存与内存挑模型和量化，一次选好显卡、上下文、KV 和槽位，看清每份配置要多少资源；上下文最长 1M（超过 262K 自动启用 YaRN，实验性），并发卡片建议同时处理多少请求。模型目录含 Qwen3.8-Flash-Next、Swift 1.5、Coder、Unsloth 和 Qwen3.6-35B-A3B，社区 OrcaRouter 去审查版 IQ3_XXS 可以导入（仅文本）。多个 Strata 版本共用一份权重时，配置按版本标注，相同副本合并，旧版本可以清理也能恢复。已经下载过的 GGUF 用“使用已有模型”直接选用：检查分片是否齐全，原地启动，不必重新下载。每个模型都按上游实测估算本机速度；“官方 / 社区 · 无审查”切换可以选用标注清楚的社区版，固定版本、校验 SHA-256，还能从 Hugging Face 自动发现。

03

聊天、API、MCP 与 Agent 接入

复制本机地址，按向导接入 Cursor、Codex、Claude Code、Cherry Studio 等客户端。在线验证逐步检查服务身份、模型、能力和一次测试请求，每步都有状态和耗时；公共聊天参数与 MCP 集中配置。聊天支持流式回复、附件和思考过程，按服务保存聊天历史，可搜索、重命名、删除和导出。公式用 KaTeX 排版，可设置思考长度上限，回答里的 HTML 可以在沙箱中直接预览。

04

用量与监控

用量面板先给出请求、成功率、失败、Token 和生成速度，再展开趋势、调用来源、请求结果、延迟与缓存复用，统计不抓请求正文。硬件与服务趋势保留采样缺口；多显卡逐卡显示，Apple 芯片按统一内存中 GPU 可用的部分显示；桌面浮条默认关闭，需要时再开。AMD 显卡在引擎没有读数时，会从 AMD 驱动读取负载、显存、温度、功耗和频率。

05

一键提速与按任务调参

默认的“一键提速”先体检显存余量与长上下文，不重启就实测短回答和长回答，结果另存为可回滚的新配置版本。高级模式按聊天、编程／Agent、长文任务比较受支持的参数，或对比多个并发设置；看质量、速度和占用后再应用或恢复，不保证固定提速。

06

Benchmark 与排行榜

在核验上限内跑上下文档位、串行七类场景或并发阶梯，留存历史并对照条件，身份不足就不下提速结论。同意后可匿名分享结果，在公开排行榜上按同模型、同量化对比不同硬件。

Strata 与 Manager如何协作

Strata 是一款开源的本地大模型推理引擎，利用 CPU 与 GPU 协同运行模型。Strata Manager 把它装进一个桌面工作台：首次上手引导、模型下载与多版本配置、服务启停、API 验证与用量、Agent 接入、监控调优，以及共享的 Benchmark 排行榜。

Strata · 推理引擎
加载受支持的模型权重，协调 CPU 与 GPU 执行推理，并通过本地 API 为聊天应用与开发工具提供服务。
Strata Manager · 桌面管理工具
管理运行环境、跨 Strata 版本的模型配置和服务生命周期，提供聊天、API 在线验证、用量统计、硬件监控、参数调优、可选上传的 Benchmark 排行榜，以及 Cursor、Codex、Claude Code 等接入向导。

  • 总览

    总览 · 服务与硬件一屏可见

    服务启停、显存和内存占用、生成速度、最近请求与今日 API 集中在一页。

  • 性能评估

    Benchmark · 上下文档位

    在模型核验上限内按档位串行测试，并覆盖实际最大上下文。对比预填充、解码、请求耗时与资源占用。

  • 运行环境

    Strata · 下载来源与校验

    选官方来源、HTTPS 镜像或本地 ZIP；装之前按官方长度和 SHA256 核验完整包。

  • 服务发现

    服务 · 运行中实例

    Windows 上查看实际加载状态、模型、配置和 API 地址；优先接回已有 Manager 后台。

  • 模型配置

    运行配置 · 编辑与校验

    图形控件或 JSON 调模型与硬件参数，校验配置并保留备份；启动快捷表单会读引擎 --help。

  • 聊天与接入

    聊天 · 与本机模型协作

    管理会话、加附件、看流式回复；结构化输出和受支持的工具都在这里。

  • 参数调优

    调优 · 比较参数配置

    按聊天、编程／Agent、长文选场景，比较质量、速度和占用后再应用。

  • 公共聊天默认值

    公共设置 · 按需继承参数

    新模型默认继承公共生成参数和 MCP 开关；旧专用值保持独立，主动开启继承后才跟随。

  • API 与外部助手

    连接 · 集中配置客户端

    选连接目标、保存应用访问密钥，复制 API 或 MCP 配置；向导含 Cursor、Codex 示例。

  • 应用更新

    应用更新 · 先阅读，再确认

    离线看随包双语日志，检查新版本并确认安装；应用更新核验 Tauri 签名，可走 GitHub 镜像并回退官方源，与引擎、模型下载分开。

  • 近期服务采样

    服务状态 · 查看近期活动

    最多 60 个近期采样，生成和输入处理分开；空闲速度标成“最近生成”，停掉或断联就藏实时指标。

  • 应用偏好

    设置 · 调整工作台偏好

    设置拆成公共设置、桌面监控、聊天默认、API、显存与会话、应用更新和关于。

  • 语言

    语言 · 跟随系统或随包资源

    可跟随系统，或选简中、繁中、英、日、韩、德、法、西、葡、俄十种随包语言。

  • 按需打开的桌面监控

    独立浮条 · 紧凑监控

    默认关闭。条形（单行／两行）或详细面板、字号和指标排序配色；纯指标可拖，操作在右键菜单，Windows 上可收起到任务栏监控。
