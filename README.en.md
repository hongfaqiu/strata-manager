# Strata Manager

**[English product overview](README.md)** · **[简体中文](README.zh-CN.md)**

Strata Manager is an open-source desktop workspace for [Strata](https://github.com/Niko1221/Strata) local inference: runtime setup, model and service management, chat, monitoring, tuning and benchmarking.

[Website](https://hongfaqiu.github.io/strata-manager/en/) · [Documentation](https://hongfaqiu.github.io/strata-manager/docs/index.en.html) · [Latest stable release](https://github.com/hongfaqiu/strata-manager/releases/latest) · [Changelog](CHANGELOG.md)

The full English README and real interface screenshots are maintained in [README.md](README.md). Its homepage cover shows the complete Overview with the top-right service status closed. Download the app from the [website download section](https://hongfaqiu.github.io/strata-manager/en/#get-started) and follow changes in the [website changelog](https://hongfaqiu.github.io/strata-manager/docs/changelog.en.html).

This compatibility entry keeps existing English README links working.

Version **0.1.8 is a release candidate, pending publication**. Published packages are listed on the [latest stable release page](https://github.com/hongfaqiu/strata-manager/releases/latest); the [daily experience features](docs/DAILY_EXPERIENCE.md) introduced in 0.1.7 continue in 0.1.8.

The [0.1.8 candidate](README.md#018-release-candidate) adds detected running-service management and automatic reconnection on Windows, system language selection with ten bundled language packs, and a monitor visibility switch with three layouts, 8–36px text and 1–8 ordered metrics from eleven. Labels default on; status text and edge snapping default off. Some advanced tools and original service logs still use English.

Screenshots were refreshed from the 0.1.8 candidate on October 14, 2026, using the actual application and components with isolated example data. View [running services](docs/screenshots/running-services.en.webp), [language settings](docs/screenshots/language-settings.en.webp), [monitor settings](docs/screenshots/floating-monitor-settings.en.webp) and the [full gallery](README.md#explore-the-workspace). They do not establish installer or inference acceptance; see the [capture record](docs/screenshots/README.md) and [verification limits](docs/VERIFICATION.md).
