# Strata Manager

[Read the English product overview](README.md) · [简体中文](README.zh-CN.md)

Strata Manager is a desktop workspace for managing the Strata runtime and local model services: installation and matching Windows x64 ZIP updates, model configurations, and service lifecycle, with chat, monitoring, usage statistics and tuning alongside them.

The English README, current-source feature descriptions and refreshed screenshots are maintained in [README.md](README.md). Published capabilities and packages are listed in the [v0.1.0 release entry](https://github.com/hongfaqiu/strata-manager/releases/tag/v0.1.0). This file keeps older links working.
